About SignaLab

Flask + SQLite + OpenCV + HOG + SVM signature writer classification prototype. The verification model is trained separately from explicitly labeled genuine and imitation examples.

Important limitations

The writer classifier needs multiple real samples per writer. Unknown-writer rejection uses a heuristic threshold based on training data and is not calibrated for deployment. Genuine/forged verification requires independently labeled imitation examples and held-out evaluation. Synthetic signatures are only suitable for UI demonstrations.

Protect signature data: obtain permission to collect it, limit access, and remove it when no longer needed.
