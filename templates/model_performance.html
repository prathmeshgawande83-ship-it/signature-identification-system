How to interpret these results

These metrics use cross-validation over the samples stored in this application. If samples are near-duplicates or not representative, scores can be optimistic. For a fair research result, evaluate against an independent public dataset or a writer-disjoint/held-out test set. Writer identification is not the same task as verifying whether a signature is forged.
